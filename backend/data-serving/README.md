# Data Serving Service

Read-only backend built on FastAPI for exposing processed seismic data stored in PostgreSQL/PostGIS by the SEG-Y processing service.

## Purpose

This service consumes the processed outputs already generated by backend 1:

- `segy_files`
- `seismic_lines`
- `seismic_shot_points`
- `seismic_traces`

It exposes GeoJSON responses to the frontend without handling user authentication or file processing workflows.

## Stack

- Python 3.12+
- FastAPI
- SQLAlchemy 2
- GeoAlchemy2
- PostgreSQL/PostGIS
- Pydantic v2

## Local setup

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Copy `.env.example` to `.env` and set `DATABASE_URL`.
4. Start the API with:

```bash
uvicorn app.main:app --reload
```

## Planned endpoints

- `GET /api/health`
- `GET /api/segy-files/{file_id}/processed/summary`
- `GET /api/segy-files/{file_id}/processed/line`
- `GET /api/segy-files/{file_id}/processed/lines`
- `GET /api/segy-files/{file_id}/processed/shot-points`
- `GET /api/segy-files/{file_id}/processed/traces`

The API is intentionally read-only and expects processed data already present in PostGIS.
